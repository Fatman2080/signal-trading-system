### 2. 加载因子

```python
    factors = json.load(f)
```

### 3. 计算因子
每个因子都包含一个独立的 `calculate_factor(df)` 函数。您需要提供一个包含 OHLCV 数据的 DataFrame。

**数据格式要求**:
- 类型: `pandas.DataFrame`
- 列名 (不区分大小写): `Open`, `High`, `Low`, `Close`, `Volume`
- 索引: `datetime` (推荐) 或 `int`

**调用示例**:
```python
import pandas as pd

# 准备数据
df = pd.read_csv('your_data.csv') 

# 遍历计算
for factor in factors:
    print(f"正在计算: {factor['factor_name']} (Sharpe: {factor['sharpe']:.2f})")
    
    # 动态执行代码
    exec(factor['code'], globals())
    
    # 调用函数
    signal = calculate_factor(df)
    
    # ⚠️ 重要：方向校准
    # 部分因子夏普为负，意味着它是反向指标，需要乘以 direction
    final_signal = signal * factor['direction']
    
    # ⚠️ 重要：标准化 (Z-Score)
    # 原始信号量纲不一，建议使用扩展窗口 Z-Score 进行标准化
    z_score = (final_signal - final_signal.expanding(20).mean()) / (final_signal.expanding(20).std() + 1e-6)
    
    print(z_score.tail())
```

## ⚠️ 注意事项

1.  **未来函数 (Look-ahead Bias)**: 所有因子代码内部已尽量避免未来函数，但在标准化（Z-Score）时，请务必使用 `expanding` 或 `rolling` 窗口，**切勿使用全局均值** (Global Mean)，否则会引入未来数据。
2.  **数据清洗**: 输入的 DataFrame 请确保没有 `NaN` 或 `Inf` 值，否则可能导致计算报错。
3.  **依赖库**: 因子代码仅依赖 `pandas` 和 `numpy`，无其他第三方库依赖。
